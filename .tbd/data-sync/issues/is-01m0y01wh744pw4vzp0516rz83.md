Implement the normative byte-oriented inline scanner for math, independent of Marko.

Files and functions:
- src/flowmark/preservation/scanner.py: scan_protected_regions(), scan_inline_scope(), scan_dollar_runs(), scan_backtick_runs(), scan_paren_math(), scan_composite_math(), scan_inline_environments(), escape_is_even(), and arbitrate_candidates().
- src/flowmark/preservation/registry.py: bind stable recognizer priority and region kinds.
- tests/test_preservation_scanner.py: a small set of state transitions, byte offsets, candidate overlap, and unmatched-fallback invariants not cleanly isolated by CLI goldens.

Scan normalized UTF-8 bytes in paragraph/heading/table-cell scopes. Enforce escape parity, blank-line boundaries, run consumption, DOUBLE fallback SINGLE pairing, exact GitLab/MyST backtick-run closure, environment-name rules, and the specified earliest-start/priority/longest/kind arbitration. Do not use the public atomic-pattern regex tuples as the recognition contract and do not add math to them.

Acceptance: FM-MATH-INLINE-001 shared cases pass through scanner diagnostics/integration as they become connected, adversarial inputs stay linear, and every emitted region is sorted, bounded, and non-overlapping.
