Two shapes where Python is unstable and flowmark-rs is not, so fixing them here will
change bytes the port must then match (flowmark-rs: fmr-dlu9).

**E — blockquote holding a heading then prose** (CommonMark 0228, 0229, 0230, 0232).
Passes oscillate between splitting the quote in two and rejoining it:

    input   "> # Foo\n> bar\n> baz\n"
    pass 1  "> # Foo\n\n> bar baz\n"
    pass 2  "> # Foo\n> bar baz\n"

**F — nested list indentation** (CommonMark 0307, 0315, 0319). The second pass inserts a
blank line after the outer item, turning a tight list loose:

    pass 1  "- foo\n  - bar\n\n    - baz\n\n      bim\n"
    pass 2  "- foo\n\n  - bar\n\n    - baz\n\n      bim\n"

84 ledger entries across 14 documents. Because Rust is already stable on both shapes, the
decision here is which port's current output is the intended one — pin that as a shared
case first, then align whichever port differs.
